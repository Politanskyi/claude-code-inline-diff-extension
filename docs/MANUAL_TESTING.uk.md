# Ручна перевірка в живому Cursor

Ці пункти потребують входу в Cursor і в Claude, тому автоматично не перевіряються. Логіка під ними покрита автотестами: 90 unit-тестів і 16 e2e-тестів, які проходять у Cursor 3.32.4 (темна й світла тема) і у VS Code 1.148 з імітованими пейлоадами хука. Червоні блоки через `~/.cursor/argv.json` у Cursor 3.32.4 перевірено автотестом.

## Результат живої перевірки (Cursor 3.32.4 + Claude Code 2.1.332, macOS, 27.11.2026)

Перевірено наживо, з правками з панелі офіційного розширення Claude Code:
- [x] Хук викликається з панелі Claude Code (Edit, Write, Bash у git-репозиторії); знімок зберігається з `session_id`.
- [x] Червоні блоки через `~/.cursor/argv.json`, кольори синтаксису теми (One Dark Pro), зелені рядки, змінені слова, пігулка під зміною, плаваючі Undo All / Keep All, статусбар, бейджі.
- [x] Keep (кнопка й Cmd+Y), Undo (кнопка й Cmd+N), автоперехід до наступної зміни й до наступного файлу.
- [x] Новий файл від Claude відкривається сам і підсвічений цілком; «2 files · 2 changes».
- [x] Undo з поясненням: причина доходить до Claude через хук.
- [x] Правка користувача всередині зміни Claude не потрапляє в знімок «до».
- [x] Підсвічування відновлюється після перезапуску Cursor.

Знайдено й виправлено під час перевірки: вкладки, відновлені під час старту, не підсвічувались; конфлікт клавіш із розширеннями-розкладками (IntelliJ IDEA Keybindings займає Cmd+Y, Cmd+N, Cmd+Enter) — тепер є команда **Fix Shortcut Conflicts**; причини Undo губились у проєктах без git.

Відмічайте `[x]`. Якщо щось не так, запишіть версію Cursor, версію розширення Claude Code і вивід **Output → Claude Inline Diff**.

## A. Встановлення
- [ ] `cursor --install-extension claude-inline-diff.vsix` встановлює без помилок.
- [ ] Команда **Enable Inline Removed-Code Blocks** додає рядок у `~/.cursor/argv.json`, коментарі у файлі збережені.
- [ ] Після **повного** перезапуску **Show Hook Status** показує `editorInsets: enabled` (у Cursor 3.32.4 автотест це підтвердив; перевірте на своїй версії).
- [ ] **Install Claude Code Hook** додає 3 записи в `~/.claude/settings.json`. Резервна копія є, ваші інші хуки й налаштування на місці.
- [ ] У панелі Claude Code → Customize → Hooks видно наші хуки (PreToolUse, PostToolUse, UserPromptSubmit).
- [ ] Кнопка **Enable "Edit automatically"** змінює режим нових розмов на Edit automatically.

## B. Перша правка через панель Claude Code
- [ ] Нова розмова, режим Edit automatically, промпт «зміни функцію X у файлі Y». Файл відкривається сам, фокус лишається в чаті.
- [ ] Статусбар показує `Claude editing Y`, потім `1 file · N changes`.
- [ ] Видалені рядки показано **червоними блоками між рядками**, шрифт і висота рядка збігаються з редактором, синтаксис кольоровий.
- [ ] Додані рядки зелені, змінені слова підсвічені сильніше (з обох боків).
- [ ] На смузі прокрутки є зелені й червоні маркери.
- [ ] У Explorer і на вкладці є бейдж із кількістю змін.
- [ ] Офіційна diff-вкладка Claude **не** відкривається (у режимі Edit automatically).

## C. Керування
- [ ] Пігулка одна: під зміною біля курсора, а при наведенні миші переходить під зміну біля миші.
- [ ] Кнопка **Keep** у пігулці працює, курсор переходить до наступної зміни в цьому файлі; після **Undo** лишається на місці.
- [ ] Кнопка **Undo** повертає старий код, файл збережено (немає крапки «не збережено»).
- [ ] Стрілки ⌃ ⌄ у пігулці перемикають зміни, лічильник «2 of 5» правильний.
- [ ] Плаваючі **Undo File / Keep File** унизу праворуч діють лише на поточний файл; у файлі без змін Claude там **Keep all changes / Review Next File**.
- [ ] **Alt+J / Alt+K** перемикають зміни у файлі, **Alt+L / Alt+H** — файли.
- [ ] Під чатом Claude Code список **Claude Changes**: Undo All / Keep All / Review угорі, ✕ / ✓ на рядку файлу, клік відкриває файл.
- [ ] Undo або збереження файлу, поки Claude виконує Bash-команду, не з'являються як зміна Claude.
- [ ] Курсор у зміні → **Cmd/Ctrl+Y** залишає, **Cmd/Ctrl+N** скасовує.
- [ ] Курсор **поза** зміною → Cmd+N створює новий файл, Cmd+Y працює як Redo (наші клавіші не заважають).
- [ ] Фокус у панелі Claude Code → Cmd+N / Cmd+Y / Cmd+Esc / Alt+K працюють як в офіційному розширенні.
- [ ] **Cmd/Ctrl+Enter** / **Cmd/Ctrl+Shift+Backspace** залишає або скасовує весь файл. Поза змінами Claude Cmd+Enter працює як звичайно.
- [ ] Після Keep останньої зміни у файлі курсор лишається в цьому файлі (як у Cursor); наступний файл — Alt+L або Review Next File.
- [ ] Cmd/Ctrl+Z одразу після Keep повертає зміну на рев'ю.
- [ ] Cmd/Ctrl+Z після Undo повертає текст Claude, і зміна знову підсвічена.
- [ ] Коли Claude правує відкритий файл, редактор прокручується до нової зміни й на мить її підсвічує.
- [ ] Схема `keybindingScheme: alt`: Cmd/Ctrl+Alt+Enter / Backspace працюють, Cmd+Y/N більше не перехоплюються.
- [ ] Alt+F5 / Shift+Alt+F5 переходять між змінами, стрілки ▲ ▼ у статусбарі теж.

## D. Ваші правки під час рев'ю
- [ ] Ви набираєте текст **поза** змінами Claude, і він **не** стає зеленим.
- [ ] Ви редагуєте **всередині** зміни Claude, і це стає частиною зміни (Reject прибирає й вашу правку в цьому блоці).
- [ ] Claude робить ще одну правку того самого файлу. Рев'ю накопичується, «до» лишається станом перед першою правкою.

## E. Нові й видалені файли, Bash
- [ ] Claude створює новий файл → весь вміст зелений. Reject file питає підтвердження й переносить файл у кошик.
- [ ] Undo після цього повертає файл.
- [ ] Claude змінює файли через Bash (наприклад `sed -i` або форматер) у git-репозиторії → зміни з'являються з позначкою «via Bash» у Claude Changes.

## F. Панелі, кроки, фідбек
- [ ] **Claude Changes** під чатом: файли видно з «+N −M», ✕ / ✓ працюють, клік відкриває файл на першій зміні.
- [ ] Дві паралельні розмови Claude → у панелі групування по сесіях.
- [ ] **Claude Steps**: кожен промпт є окремим кроком. *Revert to before this step* повертає файли, Undo скасовує відкат.
- [ ] **Reject з поясненням** (кнопка «…»): введіть причину й надішліть Claude наступне повідомлення. Claude враховує причину (видно з його відповіді).

## G. Спрощений режим і стабільність
- [ ] Без рядка в `argv.json` (або з `deletedLines.renderer: decoration`): червона риска, «−N lines removed», наведення показує старий код із кнопками.
- [ ] Агент Cursor (не Claude) редагує файл → наше розширення його **не** підсвічує.
- [ ] Великий файл (5000+ рядків) з кількома змінами: прокрутка плавна, немає підвисань.
- [ ] Світла тема: кольори читабельні.
- [ ] Windows: хук спрацьовує (немає помилок у панелі Claude Code; `.claude-review/baselines` з'являється).

## H. Видалення
- [ ] **Uninstall Claude Code Hook** прибирає тільки наші записи, повертає режим дозволів, видаляє скрипт.
- [ ] Видалення розширення + повний перезапуск: якщо крок вище пропущено, перевірте, чи прибрав хуки `vscode:uninstall`. Це питання сумісності з Cursor.
