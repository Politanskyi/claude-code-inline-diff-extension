# Ручна перевірка в живому Cursor

Ці пункти потребують входу в Cursor і в Claude, тому автоматично не перевіряються. Логіка під ними покрита автотестами: 167 unit-тестів і 18 e2e-тестів, які проходять у Cursor 3.32.4 (темна й світла тема) і у VS Code 1.148 з імітованими пейлоадами хука. Червоні блоки через `~/.cursor/argv.json` у Cursor 3.32.4 перевірено автотестом.

## Результат живої перевірки (Cursor 3.32.4 + Claude Code 2.1.332, macOS, 27.11.2026)

Перевірено наживо, з правками з панелі офіційного розширення Claude Code:
- [x] Порівняння поруч із правками агента Cursor (0.1.9): групування змін однакове (регіони правок Claude), фон видалених рядків той самий (81,32,41), видалений текст одним кольором без підсвітки слів, пігулка тих самих розмірів (24 px) і кольорів, але у власному рядку, над файлом зі змінами Cursor наші кнопки не показуються.
- [x] Хук викликається з панелі Claude Code (Edit, Write, Bash у git-репозиторії); знімок зберігається з `session_id`.
- [x] Червоні блоки через `~/.cursor/argv.json` (видалений текст одним кольором, як у Cursor), зелені рядки, пігулка під зміною, плаваючі Undo File / Keep File ⌘⏎, список Claude Changes під чатом, статусбар, бейджі.
- [x] Keep (кнопка й Cmd+Y), Undo (кнопка й Cmd+N), після Keep перехід до наступної зміни у файлі; Cmd+Z після Keep і після Undo; Alt+J/K, Cmd+Enter, Cmd+Alt+PageDown.
- [x] Новий файл від Claude підсвічений цілком і має позначку new; Undo переносить його в кошик після підтвердження. Bash-правка має позначку Bash.
- [x] Undo з поясненням (контекстне меню): причина доходить до основного агента Claude через хук (не до субагента).
- [x] Правка користувача всередині зміни Claude не потрапляє в знімок «до».
- [x] Підсвічування відновлюється після перезапуску Cursor.

Знайдено й виправлено під час перевірки: вкладки, відновлені під час старту, не підсвічувались; конфлікт клавіш із розширеннями-розкладками (IntelliJ IDEA Keybindings займає Cmd+Y, Cmd+N, Cmd+Enter) — тепер є команда **Fix Shortcut Conflicts**; причини Undo губились у проєктах без git.

Відмічайте `[x]`. Якщо щось не так, запишіть версію Cursor, версію розширення Claude Code і вивід **Output → Claude Inline Diff**.

## A. Встановлення
- [x] `cursor --install-extension claude-inline-diff.vsix` встановлює без помилок.
- [x] На чистій системі (без хука) список **Set Up** відкривається сам (лише у вікні з фокусом, навіть коли відкрито кілька вікон), усі три пункти відмічені й пояснені; Enter ставить хук, вмикає Edit automatically, додає рядок в `argv.json` і пропонує **Quit Cursor**. Esc нічого не змінює.
- [x] Після **Uninstall Claude Code Hook** над списком Claude Changes (навіть із файлами історії) є рядок «Hook not installed … Set Up», а в статусбарі — **Claude Inline Diff: Set Up**; після Set Up обидва зникають, в інших вікнах — коли вони отримують фокус. (інші вікна після фокусу не перевіряли)
- [x] Без рядка в `argv.json` **Show Hook Status** показує `editorInsets: not enabled`, а Set Up пропонує червоні блоки; з рядком і після повного перезапуску — `enabled`, і пункт зникає. (перевірено за логом розширення: `editorInsets not enabled` до перезапуску, `available` після; без рядка Set Up мав три пункти, з рядком — два)
- [x] Команда **Enable Inline Removed-Code Blocks** додає рядок у `~/.cursor/argv.json`, коментарі у файлі збережені.
- [x] Після **повного** перезапуску **Show Hook Status** показує `editorInsets: enabled` (у Cursor 3.32.4 автотест це підтвердив; перевірте на своїй версії). (за логом розширення, Cursor 3.32.4)
- [x] **Install Claude Code Hook** додає 5 записів у `~/.claude/settings.json` (до 0.3.4 — 4). Резервна копія є, ваші інші хуки й налаштування на місці. (через Set Up)
- [x] У панелі Claude Code → Customize → Hooks видно наші хуки (PreToolUse, PostToolUse, UserPromptSubmit, Stop; з 0.3.4 ще SessionStart).
- [x] Кнопка **Enable "Edit automatically"** змінює режим нових розмов на Edit automatically. (через Set Up: `defaultMode: acceptEdits`)

- [x] Автооновлення в ізольованому Cursor: 0.2.3 → 0.2.4 і 0.2.9 → 0.3.0 з двома вікнами (ставить одне вікно, друге пропонує Reload Window при фокусі). У звичайному Cursor: 0.3.1 → 0.3.2 з релізу GitHub, `sha256 checked`.
- [x] Автооновлення: зі старішою версією і `update: install` розширення за хвилину після старту саме ставить останній реліз і пропонує Reload Window (в Output: `update: installed X (… sha256 checked)`); з `notify` — лише повідомлення з кнопкою Update; з `off` — запитів немає; **Check for Updates** на останній версії каже, що вона остання. (`notify` і `off` — в окремому профілі Cursor з 0.3.2: `notify` лише пише «0.3.3 is available» і нічого не ставить, `off` не робить запиту)

## B. Перша правка через панель Claude Code
- [x] Нова розмова, режим Edit automatically, промпт «зміни функцію X у файлі Y». Файл з'являється в Claude Changes; файл сам не відкривається (як у Cursor).
- [ ] Статусбар показує `Claude editing Y`, потім `1 file · N changes` (підсумок видно лише тоді, коли список Claude Changes згорнутий або прихований). (`1 file · 2 changes` у згорнутому стані перевірено; `Claude editing Y` майже не видно: між Pre- і Post-хуком менше часу, ніж інтервал опитування)
- [x] Видалені рядки показано **червоними блоками між рядками**, шрифт і висота рядка збігаються з редактором, текст одним кольором.
- [x] Додані рядки зелені. З `highlightWords: true` видалені слова позначені у видалених рядках.
- [x] На смузі прокрутки є зелені й червоні маркери.
- [x] У Explorer і на вкладці є бейдж із кількістю змін.
- [x] Офіційна diff-вкладка Claude **не** відкривається (у режимі Edit automatically).

## C. Керування
- [x] Пігулка одна: під зміною біля курсора, а при наведенні миші переходить під зміну біля миші.
- [x] Кнопка **Keep** у пігулці працює, курсор переходить до наступної зміни в цьому файлі; після **Undo** лишається на місці.
- [x] Кнопка **Undo** повертає старий код, файл збережено (немає крапки «не збережено»).
- [x] Стрілки ⌃ ⌄ у пігулці перемикають зміни, лічильник «2 of 5» правильний.
- [x] Плаваючі **Undo File / Keep File** унизу праворуч діють лише на поточний файл; у файлі без змін Claude там **Keep all changes / Review Next File**.
- [x] **Alt+J / Alt+K** перемикають зміни у файлі, **Alt+L / Alt+H** — файли.
- [x] Під чатом Claude Code список **Claude Changes**: Undo / Keep (один файл) або Undo All / Keep All (кілька) і Review угорі, поки Claude працює — лише Review; Undo All питає Confirm; ✕ / ✓ на рядку файлу, клік відкриває файл.
- [x] Undo або збереження файлу, поки Claude виконує Bash-команду, не з'являються як зміна Claude.
- [x] Курсор у зміні → **Cmd/Ctrl+Y** залишає, **Cmd/Ctrl+N** скасовує.
- [x] Курсор **поза** зміною → Cmd+N / Cmd+Y роблять те, що їм дає ваша розкладка (наші клавіші не заважають): зі стандартною — новий файл і Redo, з IntelliJ IDEA Keybindings — Source Action і Quick Definition.
- [x] Фокус у панелі Claude Code → Cmd+N / Cmd+Y / Cmd+Esc / Alt+K працюють як в офіційному розширенні. (Cmd+Y нічого не робить; Cmd+N — новий файл, бо `claudeCode.enableNewConversationShortcut` вимкнено за замовчуванням; Alt+K — лише в редакторі; Cmd+Esc повертає фокус у редактор)
- [x] **Cmd/Ctrl+Enter** / **Cmd/Ctrl+Shift+Backspace** залишає або скасовує весь файл. Поза змінами Claude Cmd+Enter працює як звичайно.
- [x] Після Keep останньої зміни у файлі курсор лишається в цьому файлі (як у Cursor); наступний файл — Alt+L або Review Next File.
- [x] Cmd/Ctrl+Z одразу після Keep повертає зміну на рев'ю.
- [x] Cmd/Ctrl+Z після Undo повертає текст Claude, і зміна знову підсвічена.
- [x] Коли Claude правує відкритий файл, вигляд не прокручується (як у Cursor); з `followClaude: true` прокручується до нової зміни й на мить її підсвічує.
- [x] Схема `keybindingScheme: alt`: Cmd/Ctrl+Alt+Enter / Backspace працюють, Cmd+Y/N більше не перехоплюються.
- [x] Alt+F5 / Shift+Alt+F5 переходять між змінами.

## D. Ваші правки під час рев'ю
- [x] Ви набираєте текст **поза** змінами Claude, і він **не** стає зеленим.
- [x] Ви редагуєте **всередині** зміни Claude, і це стає частиною зміни (Undo прибирає й вашу правку в цьому блоці).
- [x] Claude робить ще одну правку того самого файлу. Рев'ю накопичується, «до» лишається станом перед першою правкою.

## E. Нові й видалені файли, Bash
- [x] Claude створює новий файл → весь вміст зелений. Undo File питає підтвердження й переносить файл у кошик. (Undo в пігулці робить те саме, 0.2.5)
- [x] Undo після цього повертає файл. (через **Revert Last Keep/Undo** з палітри: вкладку видаленого файлу закрито, тож Cmd+Z у іншому файлі — звичайний undo)
- [x] Claude змінює файли через Bash (наприклад `sed -i` або форматер) у git-репозиторії → зміни з'являються з позначкою «Bash» у Claude Changes.

## F. Панелі, кроки, фідбек
- [x] Довгий список Claude Changes: шапка (N Files, Undo All / Keep All / Review) лишається вгорі під час прокрутки (0.3.1).
- [x] Поки Claude працює, у шапці немає Undo All / Keep All, а ✕ / ✓ на файлі працюють — так само, як у агента Cursor (перевірено наживо).
- [x] У заголовку **Claude Changes** видно кількість файлів, що чекають рішення (`CLAUDE CHANGES (3 FILES TO REVIEW)`), і в згорнутому стані теж; коли все вирішено, цифри немає. До першого розгортання списку у вікні цифри ще немає (0.3.4).
- [x] **Claude Changes** під чатом: файли видно з «+N −M», ✕ / ✓ працюють, клік відкриває файл на першій зміні.
- [x] Коли все переглянуто, **Claude Changes** показує всі файли поточного чату з «+N -M» від стану до чату, без Undo / Keep; Review відкриває всі зміни чату. Нова розмова з першим повідомленням очищає список («No changes to review»); без хука там кнопка **Set Up**.
- [ ] Зміни, що чекають рішення, видно в списку того чату, який їх зробив; в іншому чаті їх у списку немає; Undo All / Keep All і цифра в заголовку стосуються лише файлів зі списку (0.3.4).
- [ ] Історія окрема для кожного чату (0.3.4): новий чат показує порожній список за кілька секунд після відкриття, а якщо закрити його без повідомлень — повертаються файли попереднього; попередній чат, відкритий з історії панелі Claude Code, знову показує свої файли. Повернення до чату, який уже відкривали в цьому вікні, підхоплюється за секунду (через журнал Claude Code).
- [x] Згорнутий список лишається згорнутим, коли Claude робить нову правку (як у Cursor); пігулки й статусбар показують зміни.
- [x] Дві паралельні розмови Claude → зміни обох видно в одному списку. (друга — `claude -p` у тому ж проєкті)
- [x] **Claude Steps**: кожен промпт є окремим кроком. *Revert to Before This Step* (кнопка при наведенні або контекстне меню) повертає файли, Revert Last Keep/Undo скасовує відкат.
- [x] Чат цього вікна змінює файл іншого проєкту → файл є в Claude Changes цього вікна (Undo / Keep, потім історія чату). У вікні того проєкту її не видно зовсім: ні в списку, ні в статусбарі, ні підсвічуванням чи бейджем у відкритому файлі.
- [x] Чат цього вікна виконує `cd <інший репозиторій> && <команда, що міняє файл>` → файл є в Claude Changes цього вікна з позначкою Bash; у вікні того репозиторію його немає (ні підсвічування, ні бейджа, ні підсумку в статусбарі).
- [x] Claude змінює `~/.claude/CLAUDE.md` або `settings.json` → зміна йде на рев'ю; правка пам'яті в `~/.claude/projects/…/memory/` знімка не створює.
- [x] **Undo з поясненням** (контекстне меню на зміні → *Undo Change with Feedback for Claude…*): введіть причину й надішліть Claude наступне повідомлення. Claude враховує причину (видно з його відповіді).

## G. Спрощений режим і стабільність
- [x] Без рядка в `argv.json` (або з `deletedLines.renderer: decoration`): червона риска, «−N lines removed», наведення показує старий код із кнопками. (підказка показувалась двічі — виправлено в 0.3.3)
- [x] Агент Cursor (не Claude) редагує файл → наше розширення його **не** підсвічує.
- [x] Великий файл (5000+ рядків) з кількома змінами: прокрутка плавна, немає підвисань.
- [x] Світла тема: кольори читабельні.
- [ ] Windows: хук спрацьовує (немає помилок у панелі Claude Code; `~/.claude/inline-diff/projects/<проєкт>-…/baselines` з'являється).

## H. Видалення
- [x] **Remove Completely…** → Remove Everything: хука й режимів немає, рядка в `argv.json` немає (інші id на місці), наших клавіш у `keybindings.json` немає, `~/.claude/inline-diff` видалено, з копій лишилась одна `settings.json.bak-claude-inline-diff-…`. Після Uninstall Extension, перезапуску й нової установки список Set Up відкривається сам із трьома пунктами.
- [x] Після кількох Set Up / Uninstall поруч із `~/.claude/settings.json` лежить лише одна резервна копія.
- [x] **Uninstall Claude Code Hook** прибирає тільки наші записи, повертає режим дозволів, видаляє скрипт.
- [x] Видалення розширення + повний перезапуск: якщо крок вище пропущено, перевірте, чи прибрав хуки `vscode:uninstall`. Це питання сумісності з Cursor.
